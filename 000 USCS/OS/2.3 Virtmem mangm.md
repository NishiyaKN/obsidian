### 📜 Visão Geral
Este material aprofunda o funcionamento da memória virtual, focando nos mecanismos e políticas que o sistema operacional utiliza para gerenciá-la eficientemente. O conteúdo explica o que é um `page fault`, a importância do `Princípio da Localidade` e detalha as três principais categorias de políticas que governam o sistema: as de busca, as de alocação e as de substituição de páginas.

---

### ⚙️ O Mecanismo de Page Fault
A operação da memória virtual é centrada no tratamento de falhas de página.

* **Page Fault (Falha de Página)**: É uma **interrupção de hardware** que ocorre quando um programa tenta acessar um endereço em uma página virtual que não está carregada na memória principal (RAM).
* **Resolução**: Ao detectar a falha, o sistema operacional executa os seguintes passos:
    1.  Interrompe o processo e o move para o estado de espera.
    2.  Localiza a página necessária na memória secundária (disco).
    3.  Carrega a página em um quadro (frame) livre na RAM (operação de `page in`). Se não houver frames livres, uma política de substituição é acionada.
    4.  Atualiza a tabela de páginas do processo para mapear o novo frame.
    5.  Move o processo de volta para a fila de prontos para ser reescalonado.
* **Princípio da Localidade**: A eficiência deste mecanismo depende do **Princípio da Localidade**, que postula que os programas tendem a acessar repetidamente as mesmas áreas de memória. Assim, após um `page fault`, é muito provável que as próximas referências sejam na mesma página recém-carregada, evitando novas falhas.

### 📊 Políticas de Gerenciamento de Páginas
O desempenho do sistema de memória virtual é determinado por um conjunto de políticas que decidem como e quando as páginas são movidas e alocadas.

| Tipo de Política                                                         | Estratégia                      | Descrição Breve                                                                                                                                                    |
| :----------------------------------------------------------------------- | :------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Busca**<br>_(Quando carregar uma página?)_                             | **Paginação por Demanda**       | Uma página só é carregada do disco para a RAM quando é referenciada pela primeira vez (ou seja, quando ocorre um `page fault` para ela). É a abordagem mais comum. |
|                                                                          | **Paginação Antecipada**        | O sistema tenta prever e carregar páginas que serão necessárias em breve, antes que sejam explicitamente solicitadas, para tentar evitar futuros `page faults`.    |
| **Alocação**<br>_(Quantos frames um processo pode usar?)_                | **Alocação Fixa**               | Cada processo recebe um número máximo e fixo de frames na memória.                                                                                                 |
|                                                                          | **Alocação Variável**           | O número de frames alocados para um processo pode aumentar ou diminuir durante sua execução, com base em seu comportamento (taxa de `page faults`).                |
| **Substituição**<br>_(Qual página remover quando a memória está cheia?)_ | **FIFO** (First-In, First-Out)  | Remove a página que está na memória há mais tempo. Simples, mas pode remover páginas importantes.                                                                  |
|                                                                          | **LRU** (Least Recently Used)   | Remove a página que não é referenciada há mais tempo. Geralmente eficiente, pois aproveita a localidade temporal.                                                  |
|                                                                          | **LFU** (Least Frequently Used) | Remove a página que foi acessada o menor número de vezes. Usa um contador de acessos.                                                                              |

### 🏁 Conclusão
A eficiência de um sistema de memória virtual depende criticamente das políticas de software implementadas pelo sistema operacional. A combinação mais comum e eficaz em sistemas modernos é a **Paginação por Demanda** (para busca), que evita carregar páginas desnecessárias, junto com um algoritmo de substituição inteligente como o **LRU** (ou aproximações dele), que toma boas decisões sobre qual página remover quando a memória fica cheia. Essas políticas trabalham juntas para minimizar a sobrecarga de E/S e maximizar o desempenho do sistema.
