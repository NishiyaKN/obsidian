***1 Explique a relação entre as áreas de Inteligência Artificial, Aprendizagem de Máquina, Deep Learning e Ciência de Dados: os pontos em comum e as diferenças entre estas áreas.***
Inteligência Artificial é uma área bem ampla, que engloba tanto aprendizagem de máquina quanto deep learning. Essa área é onde se exploram algoritmos capazes de reproduzir comportamentos inteligentes. Aprendizagem de máquina, subset de inteligência artificial, engloba o deep learning e foca em algoritmos que possam ser treinados a partir da experiência. Deep Learning, subset de aprendizagem de maquina, foca em algoritmos baseados em redes neurais para aprendizagem de padrões mais complexos. A Ciência de dados está presente em todas as outras áreas, e possui um foco de obter insights a partir de dados. 

***2 Sobre aprendizagem de máquina:***

***2.1 O que é aprendizado supervisionado? Dê dois exemplos de casos de uso.***
É um metodo de aprendizado de máquina onde se utiliza dados rotulados (cada entrada possui uma saída correta já definida) para treinar o modelo. É utilizado para problemas de classificação (como por exemplo analisar uma imagem de uma fruta e categorizar se é uma maçã ou um morango, treinando com várias imagens de maçãs e morangos) e problemas de regressão (por exemplo tentar prever a temperatura atmosférica de uma cidade, treinando com dados como histórico de temperatura, umidade, direção e velocidade do vento, etc)

***2.2 Quais são os tipos de métodos de aprendizado supervisionado? Qual a diferença entre eles?***
Classificação e regressão. A classificação tem como objetivo categorizar a entrada em uma das categorias predefinidas. A regressão tem como objetivo tentar prever um valor númerico contínuo.

***2.3 Quais dados são necessários para treinar um algoritmo de aprendizado supervisionado?***
É necessário ter um conjunto de dados rotulados, onde cada dado de entrada possui uma saída correta já definida.

***2.4 O que é aprendizado não-supervisionado? Dê dois exemplos de casos de uso.***
É um método de aprendizado de máquina onde se utiliza dados não rotulados, tendo como objetivo encontrar padrões nos dados, sem definir uma resposta "correta". É utilizado para problemas de clustering, onde se possa agrupar dados semelhantes em grupos. 
Exemplo 1 - agrupar clientes de um mercado em perfis diferentes para campanhas de marketing baseado em compras passadas, frequência de compras, etc.
Exemplo 2 - sugerir itens que possam ser relevantes para um usuário de uma plataforma de e-commerce baseado nos itens de compras passadas, categoria do produto, valor, etc

***2.5 Qual a entrada de um algoritmo de aprendizado não-supervisionado?***
Conjunto de dados não rotulados, ou seja, entradas que não possuem uma resposta correta definida.

***2.6 Qual a saída de um algoritmo de aprendizado não-supervisionado?***
É um padrão encontrado nos dados, como no caso de tarefas de clusterização, são agrupamentos dos dados em diferentes grupos baseado em suas características semelhantes.

***2.7 Quais as principais métricas para se avaliar modelos de aprendizado supervisionado e não-supervisionado (e seus subtipos principais, vistos em aula)?***
Em relação aos supervisionados, para classificação temos o F1 Score, que é uma média harmônica entre a precisão e recall, e para regressão temos o RMSE, que é a média da diferença entre o valor previsto e o real (o quão errado o modelo está)
