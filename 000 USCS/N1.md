### Comp
Compilador é o que copia, transcreve, podendo ou não traduzir
Linguagem fonte pode ser C, java, pascal etc
Linguagem alvo pode ser linguagem de maquina
Analise lexica ou linear, análise de esquerda para direita, agrupando sequencias wue possueam significado coletivo (token)
Tokens sao separados por caracteres em branco
Q são espaços, tabulações etc
Computador trabalha com pilha, árvore é somente para visualização de nos humanos
Questão de prova
Gramatica e um axioma gerador, para isso as regras são recursivas
Se não for recursivas não vai gerar, se não teria que colocar uma regra para cada palavra
Diretiva é uma ordem
Automato finito reconhece linguagem regular
Automato de pilha reconhece livre de contexto
Análise sintática é a hierarquização
