## Security Zone
- Compartment where you cannot disable security
- Needs to have Cloud Guard Enabled
- Has **policies** (security zone recipes)
	- If a policy violation occurs, the operation is denied
- Example: If set so all subnets are private, denies the creation of a public subnet
### Supported Services
- Networking
- Storage
- Compute
- Database
## Security Advisor
- Unifies Security Zone, Cloud Guard, etc
