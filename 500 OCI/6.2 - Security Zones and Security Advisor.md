## Security Zone
- Compartment with a **security recipe** 
	- Collection of security policies
		- Prevents running operations that violates the policies
- Needs to have Cloud Guard Enabled
- Example: If set so all subnets are private, denies the creation of a public subnet
### Supported Services
- Networking
- Storage
- Compute
- Database
## Security Advisor
- Provides recommendatins for fixing security misconfigurations
