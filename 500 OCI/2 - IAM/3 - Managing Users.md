## Onboarding Users
- OCI Console / API
- CSV import (for large number of users and groups)
- OCI Self-Registration Profiles
	- Customizable registration flows 
### From External Sources
- **App Catalog** - from other Oracle applications
- **SCIM APIs**
- **Bridge component** - from Active Directory
- **Just-in-Time** - from a federation
## Administrator Roles
Predefined roles, don't extend to compartments
- **Identity Domain Administrator** - superuser access, delegates roles
- **Security Administrator** - system settings, security configurations and policies
- **Application Administrator** - manages applications
- **User Administrator** - manages all user, groups, memberships
- **User Manager** - manage users from a specific groups
- **Help Desk Administrator** - user support, passwd reset, auth factors, etc
- **Audit Administrator** - run reports for an identity domain
