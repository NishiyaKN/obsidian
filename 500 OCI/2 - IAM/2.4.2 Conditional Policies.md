- Evaluated to True, False or Not Applicable
## Variables
- **Request** - used for attributes about the request itself
	- `request.user.id`contains the OCID of the user who made the request
	- `request.permission='OBJECT_CREATE` allow user to create a new object in a bucket
- **Target** - used for attributes about the resource/target of interest
	- `target.bucket.name='<bucket_name>'` limit access to the specified bucket
## Conditions
- Single Condition: 
	- variable = value
	- variable != value
- Multiple conditions:
	- **any** (logical OR, if any condition is true, then evaluate to `True`)
	- **all** (locial AND, if all condition are true, then evaluate to `True`)
### Types of values
- String (needs to be inside single quotes)
	- 'johnsmith@example.com'
	- 'ocid1compartment.oc1..aaaaaaaaaph..ctehnqg756a'
- Pattern
	- HR* (matches strings that start with "HR")
	- \*HR (matches strings that end with "HR")
	- \*HR\* (matches strings that contain with "HR")
## Examples
>`Allow group DomainA/PHX-Admins to manage all-resources in tenancy where request.region='PHX`
	 People from the DomainA, PHX-Admins group, can manage all resource inside the tenancy in the Phoenix region 

> `Allow group DomainA/NetworkAdmins to manage virtual-network-family in tenancy where target.compartment.id !='ocid1`
	 People from the DomainA, NetworkAdmins group, can manage all network resource inside the tenancy, except inside the ocid1 compartment
