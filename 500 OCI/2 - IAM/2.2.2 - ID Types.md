# Identity Domain Types
### Free
- Manage access to all OCI resources
- Limit of 2000 users
### Oracle Apps
- Tied to the specific Oracle service you purchase
	- Cannot select or create on the console
### Oracle Apps Premium
- Hybrid IAM
- Used for Oracle apps that use on-premises environment
### Premium
- Inclues all features
- Limits are higher
- Brod support for hybrid IAM use cases
- Unlimited support of Oracle and non-Oracle apps
### External User
- For non employees and consumers
- Uses social logon, self-service
