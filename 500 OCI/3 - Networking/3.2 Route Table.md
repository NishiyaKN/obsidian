- Determine how the traffic flows
- Defines the path for destination
- ==**Every route table has a implicit local route, which means that subnets will be able to communicate with each other, even if the RT shows no routes==**
### Types of Route Table
- **Default Route Table**
	- Auto created whenever creating a VCN
		- When creating a VNC with the wizard, a route table for private subnet will also be created
- **Custom Route Table**
	- Manually created RT
### Route Table and Subnets
- One subnet can be associtated with only route table
	- One route table can be associated with multiple subnets
### Example Route Table

| Destination CIDR Block | Target |
| :--------------------- | :----- |
| 0.0.0.0/0              | NATGW  |
| Object Storage         | SGW    |
- This table represents a private subnet, where 
	- If the destination is the internet, hops to the NAT Gateway
	- If the destination is Oracle's Object Storage, hops to Service Gateway 
- **Destination CIDR Block**: where the traffic needs to go
	- 0.0.0.0/0 = internet
- **Target:** where to send the traffic to (the next hop)
	- IGW = internet gateway
	- SGW = service gateway
	- NATGW= NAT gateway
	- DGR = Dynamic Routing Gateway
	- LPG = Local Peering Gateway
	- Private IP
### Most Specific Rule
- The most specific IP address has priority when there is an overlap
	- 0.0.0.0/0 - generic
	- 10.0.1.24 - specific
