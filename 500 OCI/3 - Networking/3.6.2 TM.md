# Traffic Management
- Provides intelligent responses to DNS queries (redirect to specific endpoints)
	- Based on conditions set in the TM
## Components
 - **Steering policies:** rules that helps to serve DNS answers
 - **Attachment:** can attach steering policies to a public DNS zone
 - **Rule:** guidelines used by steering policies to filter responses
 - **Answer:** there is an answer pool, which contain the records that will be provided as answer (which endpoint to redirect to)
## Steering Policies Types
### Failover
- Designates primary and secondary endpoints
	- If primary is health, traffic is directed to it
	- If primary is unhealth, traffic is directed to secondary
### Load Balancer
- Define how much load each endpoint receives
	- Can be like 20% on E1, 80% on E2
- Also has a failover
### Geolocation Steering
- Based on where the end user is located
### ASN Steering (Autonomous System Numbers)
- If a DNS query is originating from a specific ASN, can steer it to a specific endpoint
### IP Prefix Steering
- Based on IP prefix of the originating DNS query
