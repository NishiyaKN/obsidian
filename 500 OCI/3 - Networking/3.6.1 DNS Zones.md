## Public Zone 
 - Resolves hostnames on the Internet
 - Hold trusted DNS records
	 - In the OCI's Nameservers
### Process
1. Create a public DNS zone
	1. Needs to have the same name as the domain name you bought
	2. Auto creates NS and SOA records
2. Delegate the zone
	1. Make the zone accessible from the internet
	2. Copy the NS records to the domain name register (like Godaddy)
3. Add records to the zone
	1. Records contain data, named RDATA, such as IP address
## Private Zone
- Resolves hostnames
	- In VCN
	- Across VCNs
	- VCN and on-prem (or any private network)
### Resources
- Private DNS Zone - contains the DNS data
- Private DNS View - contains a collection of private DNS Zones (each Zone belongs to a single View)
- Private DNS Resolver - contains configurations that serves responses to DNS queries and also
>==**DNS Resolver has DNS Views, which contain DNS Zones, which contain RDATA (records)==**
- Private DNS Resolver Endpoint
	- Set up ingress and egress in VCN
		- Listener - responds to queries from outside VNC
		- Forwarder - redirects queries to different DNS servers
