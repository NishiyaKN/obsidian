- Set of tools to monitor and troubleshoot the network
## Tools
### Network Visualizer
- Interactive visualization of the virtual network topology
	- **Regional Topology Map:** DGRs, VCN,s CPEs, gateways, etc.
	- **VCN Topology Map:** subnets, VLANs, gateways
	- **Subnet Topology Map:** instances, LB, FSS, OKE
### Network Path Analyzer
- Identify routing and security configuration issues
- Supports connectivity checks to Oracle Services Network
- Free service
- Source and destination could be OCI, On-prem, Internet
### VCN Flow Logs
- Capture network traffic information for monitoring and security
### Inter-Region Latency Dashboard
- View network health and metrics across all regions
- Not available in realms that has one region.
- Will show 2 charts:
	- Current Inter-Region Round-Trip Time
		- Real time snapshot of average of the latency
	- Inter-Region Round-Trip Time
		- Historical view of the last 30 days
### (VTAP) Virtual Test Access Points
- Mirror all traffic from a source and selected target for troubleshootin, analysis and monitoring
### Capture Filter
- Set of rules for what traffic is captured by a VTAP or Flow Log
