- Dedicated, private, physical connection between OCI and on-prem
	- Doesn't traverse the internet
- High b/w
- No egress data charger
## Connectivity Models
### FC with Oracle Partner
Least expensive, most flexible
- Oracle Edge is connected to OCI
- Partner Edge is connected to the Oracle Edge
- CPE needs to connect to the Partner Edge
	- "Partner Network"
### FC with Third-party provider
- Oracle Edge is connected to OCI
- Network Carrier needs to connect CPE to Oracle Edge
	- Needs to give Network Carrier the LOA for it to provision the Cross-Connect
### FC: Colocation with Oracle
- Oracle Edge is connected to OCI
- User Edge is connected to Oracle Edge (same FC Location)
	- Needs to give LOA to the data center provider for it to estab;osj Cross-Connect
