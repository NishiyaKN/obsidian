Reverse Proxy
- High availability and scalability
- Needs to be configured:
	- Backend set with at least 1 backend server
	- Listener
	- Securlty List that is open to the listener port
## Public LB
- Scope is a region
- Requires either a regional subnet or at least 2 AD specific subnets
	- In either case there will always be at least 2 LB in 2 different AD
		- Each requires a public and a private IP
## Private LB
- Uses 3 private IPs from the host subnet
	- 1 for primary
	- 1 for secondary
	- 1 for floating private IP addres
- Requires only one subnet to host both the primary and standby LB
## Layer 7 LB
- Understand HTTP/S
- Flexible shape: defines minimum and maximum bandwidth
	- 10 mbps to 8gbps
- Dynamic shape: automatically scales bandwidth according to demand
- Content-Based Routing
	- Can inspect the package to route the package
## Layer 4 LB
- Network Load Balancer
- Works with TCP, UDP & ICMP
- Ultra-low latency, faster than Layer 7 LB
- Preserves the source and destination IP and port
- Don't need to set b/w, auto scales
### Load Balancing Policies
- **5-Tuple Hash:** 
	- routes based source IP and port, destination IP and port and protocol
	- Default
- **3-Tuple Hash:**
	- source IP, dest IP, protocol
- **2-Tuple Hash:**
	- source IP, dest IP
