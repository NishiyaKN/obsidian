Reverse Proxy
- High availability and scalability
## Concepts
### Backend set
- List of backend servers + health check and load balancing policies
### Healtcheck policy
- Test to confirm if a backend server is available or not
	- If not, takes B.E. from rotation
- TCP level: sends a connection attemp
- HTTP level: sends a request
### Listener
- Check for incoming traffic on LB IP's address
 - Provide protocol (HTTP, TCP, etc) and port number
	 - One listener per traffic type
### Layer 7 LB
- Understand HTTP/S
- Flexible shape: defines minimum and maximum bandwidth
	- 10 mbps to 8gbps
- Dynamic shape: automatically scales bandwidth according to demand
- Content-Based Routing
	- Can inspect the package to route the package
### Layer 4 LB
- Network Load Balancer
- Works with TCP, UDP & ICMP
- Ultra-low latency, faster than Layer 7 LB
