## Internet Gateway
- Handles communication between the public subnet and the internet
- Only one per VCN is allowed
## NAT Gateway
- Handles one-way communication from the private subnet to the internet
	- Enables outbound to the internet
	- Disables inbout from the internet
- Has a public IP on behalf of private instances 
	- **Ephemeral**
	- **Reserved**
- Rejects connections initiated from the Internet
- Max of 20,000 concurrent connections
### Traffic Blocking
- Regardless of any route or security rule, you can set to block traffic flowing through the NATGW
## Service Gateway
- Used for secured access to OCI public services
- Connect to Oracle Services Network without going through the Internet
	- Only connects to resources in the same **region**
### Services CIDR Label
- String that represents all regional public IP address ranges
## Dynamic Routing Gateway
- Routes traffic from the private subnet to on-premises environment or other cloud providers
- Routes traffic between different VCNs
	- Don't need to go throught the internet
- Each DGR can attach to up to 300 VCNs
## Local Peering Gateway
- Enables communication between 2 VCNs in the same region
- Up to 10 LPG per VCN
- Each LPG can attach to up to 1 DGR
