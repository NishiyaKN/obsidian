## DNS Options within a VCN
- **Internet and VCN Resolver**
	 - Default choice
	 - Resolves hostnames in the internet and in instances on the same VCN
- **Custom Resolver** 
	- Can select DNS server of your choice
		- Internet
		- VCN
		- On-prem
- **Private DNS**
	- Resolves in VCN and across VCNs
	- Resolves between VCN and on-prem (or any private network)
## Components of DNS Service
### Domain
- Human readable name of a website
- Ex: oracle.com
### Zone
- Part of the DNS namespace
	- Administred by a single entity
- Each zone contains: 
	- SOA (start of authority record): with info about the zone
	- NS (nameserver record): with which DNS servers are responsible for answering queries for this zone
### Label
- Subdomain 
- Prepended to the zone name, separated by a period 
- Ex: www
###  Child Zone
- Independent subdomain
- Has it's own SOA and NS
- Created when a subdomain is delegated to a separate administrative entity with its own DNS servers
	- Ex: `europe.oracle.com` could be a child zone of the `oracle.com` zone
- Parent zone needs to have a special NS recoord for the child zone
	- PZ points queries to CZ
###  Resource Records
- Contains specific domain information for a particular zone
	- A: maps a domain name to IPv4 address
	- AAAA: maps a domain name to IPv6 address
	- CNAME: creates an alias from one domain name to another
	- MX: specifies the mail exchange servers for a domain
## HTTP redirects
- Can redirect all the traffic from a URL to another URL
- Can redirect specific subdomain
- Can redirect a subdomain to URL with port number
- Can permanently redirect a domain name by displaying 301 error code
