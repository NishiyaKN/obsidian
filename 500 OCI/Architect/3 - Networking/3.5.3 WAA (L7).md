# Web Application Acceleration
- Can speed up traffic on layer 7 LB only
	- Uses caching and/or compression
1. Create the WAA policy, defining if will use caching or caching & compression
2. Create a acceleration resource (attach it to a LB)
- A single policy can be attached to various LB by creating a acceleration resource in each
## Concepts
- ==**Responses can only be cached if returns HTTP code 200 to a GET or HEAD request==**
- Responses that return the Set-Cookie header are not cached
- Max size of cache: 100mb
	- Auto removes resources that are least accessed if it reaches max
- Default cache time: 10m (will remain in the cache)
	- Static content should have increased time
	- Dynamic content should have decreased time
- Cached content might not be current with the back-end
	- May need to manually purge cache
