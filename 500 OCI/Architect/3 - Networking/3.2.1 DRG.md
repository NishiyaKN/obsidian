## Types of attachment
- VCN
- RPC (connection between DRG for cross region VCN peering)
- IPsec Tunnel
- Virtual Circuit
- Loopback - to forward a traffic from a virtual cicuit attachment to an IPsec tunnel attachment within the same DRG
## Routing
- Routes traffich b/w attachments via DRG Route Tables and DRG Route Distributions
### Route Types
- Static Route - created manually (higher priority)
- Dynamic Route - imported automatically into DRG using Import Route Distributions
### DRG Route Tables
- Auto generated:
	- RT for VC, RPC, IPsec attachments
		- Uses IRD for VCN routes
			- Dynamic Route for VCN
	- RT for VCN attachments
		- Uses IRD for ALL routes
			- Dynamic route for VCN
			- Dynamic route for RPC
- Can have
	- Dedicated RT for each attachment
	- Same RT for multiple attachments
- Each attachment can have only one RT associated with it
### DRG Route Distributions
#### Import route distribution
- Controls how the route advertisements from the attachments are inserted into the DGR RT
	- Auto populates the route tables and keeps them updated
	- List of statements that contain a match criteria
- VCN Routes
- All routes
###### Flow
1. Write statement with the match criteria
2. It matches with an attachment
3. The route gets dynamically imported to the DRG RT
#### Export route distribution
- Specifies how the routes are going to be advertised to the attachments from the respective route tables
- 1 Default Export Route Distribution when creating a DRG
### ECMP
Equal Cost Multi-path Routing
- OFF by default
- Enabled on a RT
- Facilitates load-balancing of n/w traffic over multiple
	- FastConnect VC 
	- IPSect tunnels 
		- Using BGP on both
### Route Conflicts
#### Rules
- Static routes have preference over dynamic routes
- Resolved by the AS path
	- For VCN and static, AS path is empty
	- For IPSec tunner and VC, AS path is populated
#### Priority
1. Static
2. VCN
3. VC
4. IPsec tunnel
5. RPC
