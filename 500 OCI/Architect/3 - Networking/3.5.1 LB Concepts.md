#### Backend set
- List of backend servers + health check and load balancing policies
#### Healtcheck policy
- Test to confirm if a backend server is available or not
	- If not, takes BE from rotation
- **TCP level:** sends a connection attempt
- **HTTP level:** sends a HEAD or GET request
#### Shape (L7)
- Uses flexible shape, defines min and max b/w
	- From 10mbps to 8000mbps
#### SSL
- Encrypted link between the client and server
- **SSL Termination:** encrypted between client and LB, but unencrypted between LB and BE
- **Point to point SSL:** terminates SSL connection, LB unencrypts, reads, decides where to send, reencrypts and send it
- **SSL Tunneling:** LB don't terminate SSL nor unencrypts, just forwards the packets
#### Session Persistance
- All requests from a client will be sent to a single BE
	- Uses load balancer cookie
#### Certificates
- When using HTTPS, a SSL server certificate needs to be associated to the LB
	- LB terminate and decrypt the request using the certificate
#### Routing Policies (L7)
- **Path Based Routing**: routes based on the url path (/app /video /images)
- **Host Based Routing**: routes based on the hostname (api.example.com, blog.exmple.com)
#### Listener
- Check for incoming traffic on LB IP's address
 - Provide protocol (HTTP, TCP, etc) and port number
	 - One listener per traffic type
