# OCI Container Instance
- For small containerized applications
- No need to manage infrastrucutre
	- Just supply the container image
- Can run multiple containers in an instance
# Oracle Container Engine for Kubernetes
- Fully managed Kubernetes service 
- Developer features:
	- One click cluster creation
	- CLI/API support
	- Support for Arm and GPU instances
- DevOps features:
	- Autoscaling support
	- Automatic Kubernetes upgrade
	- Self-healing cluster node
## Components of a Cluster	
### Customer managed
- **Node -** Machine on which Kubernetes is installed
- **Node Pool -** Group of nodes
- **Pod -** Group of containers with shared storage and network resources (smallest unit of compute in Kubernetes)
### Oracle Managed
 - **Control Plane Node**
	- Used to manage the cluster
	- Free to use
## Types of OKE Clusters
### Enhanced Clusters
- Support all available features
- Financially backed Service Level Agreement (contractual promise with financial consequences)
### Basic Clusters
- Support core functionality
- Service Level Objective (internal goal, no promise to the customer)
## Management
### Virtual Node
- 'Serverless' option
- Only available in enhanced clusters
- Oracle handles software upgrade and patches
### Managed Node
- Customer managed nodes
	- Update, capacity
- Available on both cluster types
