## Oracle Cloud Agent
- Lightweight process that manages plugins running on instances
	- Plugins collect metrics, install OS updates, etc
### Bastion
- Allows SSH connections to an instance without public IP
### OSMH (Oracle OS Management Hub)
- Simplifies OS and patch management
- Central management
	- OCI, On-prem, third-party cloud
#### Management Agent
- Deployed for each managed instance (grouped instances managed by OSMH)
- Gathers data (patch status, compliance, etc) to the OSMH
#### Management Station
- Serves as a proxy for the OSMH for on-prem and OCI
- Mirror software repos and locally distributes updates
	- Reduces b/w for patches
- Management Agents are deployed here too in order to sync everything up
#### Other Components
##### Software Sources
- Collection of packages and modules
	- Basically repositories
- **Vendor Software Source**: OS vendor-provided content, at least 1 of this is needed
- **Custom Software Source**: use a vendor source but with filters to include or exclude certain packages
- **Versioned Custom Software Source**: immutable
##### Profiles
- Apply the same settings to multiple instances at once
	- Basically a template that defines 
		- Software sources
		- Lifecycle stage membership (developing, testing, production)
		- and group membership (group images for better management)
- Can't use profile from OCI instance to on-prem instance
##### Ksplice
- Apply security patches to Linux kernel without reboot
### Run Command
- Remotely manage compute instances by running scripts within the instance
	- Up to 4KB in the console, output up to 1KB
		- For larger files need a object storage
- No need have SSH access nor open inbound ports
- Works with all OS except Ubuntu
- Used to automate tasks or troubleshoot SSH
## Instance Console Connections
- Shows what is happening during boot
	- Used for remote troubleshooting
### Serial Console Connection
- Mainly used for Linux as it is CLI
- Uses Cloud Shell to SSH 
### VNC Console Connection
- Used for servers with GUI
- Don't use Cloud Shell
