- Rules to specify how to deal with old data
- Up to 1000 rules per bucket
- For archive storage bucket, only delete rules are supported
- Examples:
	- "After 30 days, move data to archive tier"
	- "After 180 days, delete data"
## Policy Actions
- Move to Infrequent Access
- Move to Archive 
- Delete (takes priority over other actions)
## Policy Targets
- Latest Version of Objects
- Previous Versions of Objects (if versioning is enabled)
- Uncommitted Multipart Uploads (or failed uploads)
## Object Name Filters
- Precedence: pattern exclusion, pattern inclusions, prefix inclusions
- **Prefix matching:**
	- Matches left-most characters of an object name
	- No support for wildcards
	- Ex: training/oci/ (prefix for training/oci/os.jpg)
- **Pattern matching:**
	- Matches entire object name
	- Support wildcards
	- Ex: \*.jpg
