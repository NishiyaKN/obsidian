- When creating a bucket, it can be Standard or Archive tier
	- If Standard, them the object can be uploaded to any tier
	- If Archive, them the object can be uploaded only to Archive tier
## Standard Tier
- Fast, immediate and frequent acces 
- Instantaneous retrieval
- Most recent copy of the data
## Infrequent Access
- Long term, such as backups
- Must be stored for at least 31 days
	- Available immediately after this period
- Retrieval fees
- 60% cheaper than standard
## Archive Tier
- Rarely accessed data
- Must be stored for at least 90 days
- To access an object needs to **restore** it first
	- Restore time: <1 hour
	- Download available time: 24 hours (up to 240)
## Auto-Tiering
- Learns access pattern
- Automatically move files between Standard and Infrequent Access tiers
- No retrieval fee
