- Asynchronous replication
- Source FS can be used during replication
	- Can replicate to multiple targets simultaneously
- Supports replication to AD cross regions
- Only a FS that has never been exported can be used as a target FS
## Components
### Replication Snapshot
 - Captures incremental changes in the source since the last snapshot
### Replication Interval
- Determines the requency of data replication in minutes (needs to be >=60 m)
### Replication Resource
- The control component of the replication process
	- Contains all the configuration info for the replication
- Attached to the source to capture the data
- Creates a replication snapshot and transmits to the target
### Replication Target Resource
- Receives the replication snapshot from the replication resource
- Applies the received data to the target
### Base Copy
- Initial data transfer from the source to the target
### Delta Copy
- Periodic system-driven snapshots taken on the souce for the incremental data
## Delta Cycle
Replication is:
- Idle: not capturing or applying data
- Capturing: capturing differentiated data in the source snapshot
- Transferring: tranferring and commiting snapshot data
- Applying: committing the snapshot data to the target
