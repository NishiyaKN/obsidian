## Encryption
- With customer managed keys, only works with AES keys
### In-Transit Encryption
- Secure data between instances and mounted FS
- Uses TLS v.1.2
- Needs to open TCP port 2051
- Need the `oci-fss-utils` package to run a forwared process in background (OCI FSS forwarder)
- Needs to mount the FS with a specific command for it to be encrypted
