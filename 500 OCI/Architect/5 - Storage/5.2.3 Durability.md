## Backups
- Point-in-time snapshot
- Restored as a new volume in any AD in the same region
- Can make a backup on an attached or detached volume
- Stored in object storage
### Types of Backup
- **Incremental**: only the changes since the last backup
- **Full backup**: all the changes since the volume was created
### Ways to Backup
- **Manual Backup:** on-demand
- **Policy-based backup schedule:** 
	- **Oracle defined policies**: incremental only
		- Bronze: montly, retained for 12 months + yearly , 5 years
		- Silver: Bronze + weekly (Sunday), 4 weeks
		- Gold:  Silver + daily , 7 days
	- **User defined policies**
## Clones
- Direct disk-to-disk copy
- All data is copied
- Can take up to 30m
	- If the source volume is attached, can only create 1 clone at a time
	- If not, up to 10 clones at the same time
- Can only be created in the same AD
## Cross Region Replication 
- Auto replicates data between regions asynchronously
- Not a substitute for backups
	- Replicas gives only the current version of the data
- Requires a initial synchronization
- No down time
- Don't support customer managed encryption keys
- Replica is Lower Cost by default
### Cross AD Replication
- Replicates to another AD in the same region
- No network cost 
- Basically the same limitations and features of the cross region replication
