## Attachment Types
- **iSCSI**
	- Does not use hypervisor for attaching
	- No virtualization, no overhead, max IOPS performance
	- Needs to run a few commands to access on the OS
- **Paravirtualized**
	- Light virtualization (more efficient than full virtualization)
	- Uses Hypervisor APIs to access remote storage
	- "Plug-and-play"
## Access Types
- **Read/Write (default)**
	- Can only attach to a single instance
- **Read/Write Shareable** 
	- Can attach to multiple instances (up to 8)
	- Need a clustered file system
- **Read-only Shareable**
	- Same conditions as the above
## Boot Volumes
- Encrypted by default
- Faster performance
- Backup and clone operations are supported
- Performance can be change from Balanced or Higher performance
- Data can be preserved after an instance termination
