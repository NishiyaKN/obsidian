- Storage for the web, such as images, videos, etc
	- Ideal for unstrucutred or semi-structured data
- Unlimited capacity 
- Regional service
- Accessed with via API with simple HTTP commands like Put and Get
- **Data encryption by default, cannot be turned off**
## Resources
- **Namespace:** top-level container for all buckes, globally unique name
- **Bucket:** container for storing objects
	- Needs to be unique in a region in a tenancy
	- Flat hierarchy (can simulate folder structure via prefixes, )
- **Object**: the thing to be stored + it's metadata

- Rules to specify how to deal with old data
	- "After 30 days, move data to archive tier"
	- "After 180 days, delete data"
