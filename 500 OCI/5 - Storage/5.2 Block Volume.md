- Network-attached block storage, like a virtual Storage Area Network (SAN) disk.
- Or locally attached NVMe SSD 
	- Extremely low latency
	- No RAID, images, backups done by Oracle
- Attached to a compute instance
	- Up to 32 volumes per instance
- Automatically replicated within an availability domain
- Data is managed as a fixed size block
	- Create a partition -> create a filesystem -> mount the filesystem
- From 50GB to 32TB size
## Features
- Persistent and durable
	- Can exist without a compute instance
- **Encryption by default on rest and transit, cannot turn off**
### Resizing
- Volumes can only be **expanded**, not shrunk
- **Cross region replication needs to be disabled**
- Needs to manually run commands to rescan and extend
- **Online Resizing** - expand the volume size without detaching the volume from the instance
	- Cross-region replication needs to be disabled before resizing
- **Offline Resizing** - detach the volume, resize via console/API, then reatach
	- Can also resize when restoring a volume backup or cloning an existing volume
### Volume Groups
- Simplifies the process to create time consistent backups of multiple volumes
	- Can restore an entire group of volumes from a volume group backup
