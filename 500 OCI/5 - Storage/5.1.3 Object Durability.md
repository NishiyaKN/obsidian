## Replication Policy
- Replicate objects from one bucket to another
- Can be to different regions
- Destination bucket needs to be created manually
	- It becomes read-only when applying the policy
	- Cannot be deleted untill policy is deleted or stopped
- Objects from the source uploaded before the policy is not replicated
- **Does not replicate versions, only the most recent object**
## Object Versioning
- Enable or suspended at bucket level
	- Cannot on enable on a bucket with active retention rules
- Charged for every version
- Previous versions are retained until explicitly deleted
- In order to restore a deleted object, you need to delete the delete marker
	- Deleted versions cannot be restored
## Retention Rules
- Can be locked to prevent rule deletion (retention time can be extended)
	- 14 day delay before the rule is locked
	- Not even a tenancy admin can delete a locked rule
		- Only if deleting the bucket
- Configured at the bucket level
- Can be Time-bound or Indefinte
- **Not compatible with versioning**
### Time-bound
- Object modification and deletion are prevented for the specified duration
### Indefinite
- Object modification and deletion are prevented untill the rule is deleted
