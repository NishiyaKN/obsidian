## Snapshots
- Consistent point-in-time view of the FS
- Accessible in the /.snapshot/snapshotname
- Consume no additional storage when it is taken
	- They reference the original data, don't duplicate
	- Grows in size as more differences happen in the FS
## Clones
- Based on a snapshot only
- **Source Snapshot:** snapshot used to create a clone
- **Parent File System**: FS that contains the source snapshot
- **Hydration**: process of copying metadata from the source to the clone
	- Clone can be used for regular operations while hydration is in progress
- **Clone Tree:** group of close that descend from the same root FS
## Encryption
- With customer managed keys, only works with AES keys
### In-Transit Encryption
- Secure data between instances and mounted FS
- Uses TLS v.1.2
- Needs to open TCP port 2051
- Need the `oci-fss-utils` package to run a forwared process in background (OCI FSS forwarder)
- Needs to mount the FS with a specific command for it to be encrypted
## FS Replication
- Asynchronous replication
- Source FS can be used during replication
	- Can replicate to multiple targets simultaneously
- Supports replication to AD cross regions
- Only a FS that has never been exported can be used as a target FS
- **Replication Snapshot**: captures incremental changes in the source since the last snapshot
- **Replication Interval:** determines the requency of data replication in minutes (needs to be >=60 m)
- **Replication Resource:** contains all the configuration info for the replication
	- Attached to the source to capture the data
	- Creates a replication snapshot and transmits to the target
- **Replication Target Resource:** receives the replication snapshot from the replication resource
	- Applies the received data to the target
