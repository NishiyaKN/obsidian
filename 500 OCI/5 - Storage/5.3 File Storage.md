- Uses NFS
- **Shared between multiple compute instances**
	- Can access from outside the VCN (Fastconnect, IPSec, etc)
- Hierarchical collection of documents
	- Organized into directories
- Replicated in multiple ADs
- Up to 8 exabyte
- Can make snapshots (up to 10,000)
- Don't partition disk, just mount the filesystem
## Concepts
### File System
### Mount Target
- NFS endpoint
- Lives in a subnet
- Used by the client to connect to the FS
- Provides the IP address/DNS name
- Same mount target can be reused for multiple FS
### Export
- Controls how NFS clients access FS when the connect to a mount target
- **Export Set:** collection of one or more exports
- **Export Path**: uniquely identifies the file system within the mount target
- **Export Options:** set of parameters that specify the level of access granted to NFS clients
## Use cases
- Oracle Applications Lift and Shift
- General purpose file system
