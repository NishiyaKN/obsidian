## Pre-Authenticated Requests
- Let user access objects without need for credentials
- Unique URL is generated
	- Anyone can access the object through this URL
- Expiration data required (can be no limit)
- Can't edit a pre-authenticated request
- If the creator of the PAR is deleted or loses the permissions, then the PAR will no longer work
### Targets
- **Bucket:** applies to all objects in the bucket
- **Object**: only to the specific object
- **Objects with prefix**: all objects with the specified prefix
### Access Type
- Read
- Write
- Read and Write
(cannot delete anything)
## Encryption
- Bucket is auto encrypted with Oracle managed keys
- You can set customer-managed keys
	- Keys from (OCI Vault)
	- Good for rotating keys
