The ability to understand a system's internal state by analyzing the data about what's happening in context across environments.
- Instrumentation: make the application aware of the observability platform
## Pillars of Observability
- Traces
- Logs
- Metrics
## Monitoring vs Observability

| Monitoring                             | Observability                        |
| -------------------------------------- | ------------------------------------ |
| What is the state of my systems?       | Why is my system in failed state?    |
| Collection of metrics, traces and logs | Context of metrics, traces, and logs |
| Creates the process to monitor         | Creates the potential to monitor     |
| Single plane architecture              | Traversable map architecture         |
| Understand the state of systems        | Actions to actively debug systems    |
| Tracking of systems                    | Knowledge with insights              |
| Wide view of system behaviour          | Deep view of system characteristics  |
