## Image Import/Export
- Enables sharing custom images across regions and tenancies
- Uses OCI Object Storage
	- Export the image to a bucket, copy to a bucket on target region, get the URL and import the image
- **Emulation Mode** - for VMs that don't support paravirtualized drivers from older on-prem machines
- **Paravirtualized Mode** - for machines ouside of OCI environment that support paravirtualized drivers
- **Native Mode** - Images exported from OCI
### BYOI 
- Import a custom image to OCI
	- qcow2 or VMDK
- Max size of 400gb
## Windows custom image
- Generalized - cleaned of instance specific information
- Specialized - point-in-time snapshots of the disk of a running instance
