# Oracle Functions
- Don't need to worry about infrastructure
	- Provide the code and the cloud will run it in a **container**
- Billed only for the time the function is running
- **Event Driven Architecture**
- Functions are organized into **Applications**
	- Logical groupings of functions that can share common configurations (e.g., networking settings).
- Based on Fn Project Engine (Open Source)
## How it works
1. Write the code
2. Pack the code and configuration into a container
3. Upload the container to OCI Registry
4. Set up trigger actions
	1. Direct invoke: SDK, CLI or API
	2. Event-Drive: OCI Event
5. Code is run when triggered
