- Storage for the web, such as images, videos, etc
	- Ideal for unstrucutred or semi-structured data
- Regional, public service
- Accessed with via API with simple HTTP commands like Put and Get
- Flat hierarchy (simulated folder structure via prefixes)
- **Namespace:** top-level container for all buckes, globally unique name
- **Data encryption by default, cannot be turned off**
## Tiers
### Standard Tier
- Fast, immediate and frequent acces 
- Instantaneous retrieval
- Most recent copy of the data
### Infrequent Access
- Long term, such as backups
- Must be stored for at least 31 days
- Retrieval fees
- 60% cheaper than standard
### Archive Tier
- Rarely accessed data
- Must be stored for at least 90 days
- Restore time: 1 hour
- Download available time: 24 hours (up to 40)
### Auto-Tiering
- Learns access pattern
- Automatically move files between tiers
- No retrieval fee
## Lifecycle Management
- Rules to specify how to deal with old data
	- "After 30 days, move data to archive tier"
	- "After 180 days, delete data"
