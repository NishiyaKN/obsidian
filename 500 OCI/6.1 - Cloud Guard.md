- Monitor and identify potential security issues
	- Automatically remediate when possible
	- Free service
## Components
### Target
- Resource to be examined by OCG
	- Can be a compartment for example
- Identifies resources/user actions that are insecure/risky
### Detector
- Identify issues with resources or user actions
- Flag and alert
### Problems
- Potential security issue
- Assings a risk level
### Responder: 
- Notify about and correct security problems
- Examples: Revoking user permissions, disabling a public bucket, notifying an administrator
