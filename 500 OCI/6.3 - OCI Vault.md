## Encryption
- Used to transform plain text into cipher text
	- Randomized letters and numbers
- **Key**: string stored in a file that encrypt or decrypt data
- **Symmetric Encryption**: uses a single key to encrypt and decrypt
	- Cannot be used for digital signing
	- AES is an example
- **Asymmetric Encryption**: uses a public key and private key
	- Anyone can encrypt text with the public key
	- Only the holder of the private key can decrypt 
	- RSA is an example
## HSM (Hardware Security Module)
- Physical computing device
- Tamper-evident hardware
- Used to manage ditial keys
- Performs cryptographic functions
