## Security Lists
- Basically firewall rules associated to a subnet
	- Applied to all instances inside the subnet
![](Pasted%20image%2020250723171027.png)
## Network Security Groups
- Similar to a Security List
- Only apply to specific VNICs from the VCN
	- Basically firewall rule to instance level, allows for more fine grained control
- Can be used as source or destination in the rules
