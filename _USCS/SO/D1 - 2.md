# 🖥️ Gerência de Recursos

## 🔍 Visão Geral do SO
- **Conjunto de rotinas de software executados pelo processador**
- **Modo Kernel**: Execução privilegiada com acesso total ao hardware
- Gerencia o compartilhamento do hardware para os softwares
- Estabelece uma interface (API) para os processos solicitarem ao kernel as operações sob os recursos desejados
- **Funções essenciais**:
  - ⏱️ Escalonamento de processos
  - 🧠 Alocação de memória
  - 🌐 Controle de redes
  - 🖨️ Coordenação de dispositivos E/S

## 📊 Abstração de Recursos
| Recurso Físico | Abstração do SO | Benefício |
|----------------|-----------------|-----------|
| CPU | Threads/Processos | Concorrência |
| Memória RAM | Espaço de endereçamento virtual | Isolamento |
| Disco Rígido | Sistema de arquivos | Organização hierárquica |
| Dispositivos E/S | Drivers | Padronização |

## 💡 Interfaces de Acesso

## ⚙️ Modalidades de Operação
### 🔄 Modelos de Execução
1. **Monoprogramação**:
   - Execução de um único processo por vez
   - Exemplo: MS-DOS

2. **Multiprogramação**:
   - Time-slicing (fatias de tempo)
   - Concorrência aparente
   - Exemplo: Windows 95

3. **Multiprocessamento**:
   - Núcleos múltiplos
   - Paralelismo real
   - Exemplo: Sistemas modernos (Windows 11, Linux)
