# 💻 Sistemas Operacionais I: Fundamentos

## 🖥️ Arquitetura Básica
### 🧠 Modelo von Neumann (1940)
- **Componentes essenciais**:
  - 🧮 ULA (Unidade Lógica e Aritmética)
  - 🧠 Memória principal
  - 🎛️ UC (Unidade de Controle)
  - ↔️ Dispositivos E/S

- **Características revolucionárias**:
  - Programa armazenado (40 bits/instrução)
  - 21 instruções básicas (8 bits OPCODE + 12 bits endereço)
  - Processamento sequencial

## 🔍 Hierarquia Computacional (Máquina de Níveis)
| Nível | Componente        | Função Principal                             |
| ----- | ----------------- | -------------------------------------------- |
| 6     | Aplicativos       | Soluções específicas (office, jogos)         |
| 5     | Utilitários       | Gerenciamento do sistema (antivírus, backup) |
| 4     | SO                | Controle de hardware e recursos              |
| 3     | Linguagem Máquina | Instruções binárias do processador           |
| 2     | Microprogramação  | Implementação do ISA (CISC)                  |
| 1     | Hardware          | Circuitos eletrônicos físicos                |

## ⚙️ Componentes Críticos
### 🔌 Firmware vs Microprogramação
| Característica | Firmware                           | Microprogramação                       |
| -------------- | ---------------------------------- | -------------------------------------- |
| Localização    | ROM/Flash (mobo, SSD, router, etc) | Memória de controle da CPU (CISC only) |
| Função         | Controle geral do hardware         | Implementação do ISA                   |
| Atualização    | Via software                       | Raramente (depende da arquitetura)     |

### 🔄 Ciclo de Instrução
1. **Busca** (PC → IR)
2. **Decodificação** (OPCODE)
3. **Execução** (ULA)
4. **Armazenamento** (registradores/memória)

## 📚 Registradores Fundamentais
- **PC**: Contador de programa
- **IR**: Registrador de instruções
- **AX**: Acumulador
- **PSW**: Palavra de status

## 🛠️ Utilitários 
- São programas relacionados ao modo de funcionamento e gerenciamento da máquina
- Complementam funcionalidades dos sistemas operacionais
	- 🗜️ Compactação de arquivos
	- 🛡️ Antivírus
	- 🔄 Backup automático

## 📱 Aplicativos 
- Apoia o usuário em suas tarefas
	- 📊 Suíte office
	- 🏭 Softwares industriais
	- 🎮 Jogos

## 🖥️  Sistema operacional
- Software que gerencia hardware e software
- Controla recursos compartilhados para os programas
- Conjunto de rotinas
