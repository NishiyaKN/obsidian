# 🖥️ Núcleo e Modos de Execução

## 🧠 O Núcleo do Sistema Operacional (Kernel)

### Visão Geral do Kernel
- **Função central**: Gerencia todos os recursos de hardware e software
- **Carregamento**: Inicializado durante o boot (processo de bootstrap)
- Usuários não interagem diretamente com o kernel, eles interagem com o Shell
- **Componentes críticos** (desenvolvidos em assembly):
  - Gerenciador de processos e threads
  - Controlador de memória física e virtual
  - Sistema de arquivos
  - Drivers de dispositivos

### Arquitetura do Kernel
- **Interface (API)**: Ponte entre programas e hardware
- **Programas gerenciados**: Executam com permissões limitadas
- **Hardware**: Acesso direto apenas pelo kernel

## ⚡ Mecanismos de Interrupção
- Interrupção é um sinal feito por hardware ou software, que pausa a execução de uma instrução para que seja executada outra (mais importante)
- Tornou possível a concorrência entre processos (multiprogramação)
- Sincroniza a execução de rotinas e programas
- Controla dispositivos
### Tipos de Interrupções
1. **Hardware (IRQ)**
   - Disparada por dispositivos físicos
   - Exemplo: Teclado, disco rígido
   - Tratamento via vetor de interrupções

2. **Software (TRAP)**
   - Disparada por programas
   - Exemplos: 
	   - término de um programa
	   - instrução ilegal (dividir por zero)
	   - requisição de serviços ao kernel
   - Tratamento pelo kernel

### Processo de Tratamento
1. Interrupção é relacionada a um vetor de interrupção (faz uma syscall)
2. Salva o contexto dos registradores 
3. Processador entre em modo privilegiado
4. Executa a rotina de tratamento
5. Processador volta para modo usuário
6. Restaura o contexto dos registradores

## 📞 Chamadas de Sistema
- Serve como uma porta de entrada para o kernel e seus serviços
- Sempre que um app precisa de algum serviço do sistema, faz um syscall pro kernel
- Basicamente uma API
- Cada SO possui um conjunto de rotinas diferentes, isso que gera incompatibilidades de plataformas
### Métodos de Chamada
- **Implícita**: Usado diretamente com linguagem de programação e é convertida pelo compilador (ex: fopen() em C)
- **Explícita**: Invocação direta (ex: int 0x80 em Linux/x86)

## 🛡️ Modos de Execução
- Determinada por um conjunto de bits no registrador de status (PSW)
- Por meio desse registrador o CPU verifica se pode executar a instrução ou não
### Comparação entre Modos
- **Modo Usuário**:
  - Permissões limitadas
  - Programas comuns
  - Acesso restrito à memória
  - Instruções básicas

- **Modo Kernel**:
  - Permissões totais
  - Acesso completo à memória
  - Todas as instruções disponíveis

### Mecanismos de Proteção
- Todas as operações de I/O são privilegiadas
- Antes de passar o controle ao programa, SO configura CPU no modo user
- **Timer**: Previne monopólio da CPU
- **PSW**: Registrador que controla o modo atual
