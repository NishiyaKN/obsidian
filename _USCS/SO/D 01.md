# 🖥️ Sistemas Operacionais: Arquiteturas e Gerenciamento de Processos

## 🔍 Arquiteturas de Processadores
### CISC vs RISC
| Característica | CISC | RISC |
|---------------|------|------|
| Microcódigo | Presente (camada adicional) | Ausente (hardware direto) |
| Flexibilidade | Atualizável via firmware | Fixo no hardware |
| Instruções | Complexas e variadas | Simples e padronizadas |
| Exemplos | Intel x86 | ARM, RISC-V |

**ISA (Instruction Set Architecture)**
- Define todas as instruções que um processador reconhece
- Algumas instruções são privilegiadas (modo kernel)
- Compatibilidade obrigatória entre software e ISA

## 🛠️ Componentes do Sistema
### Hierarquia de Software
1. **Firmware**: Software embutido no hardware (ex: BIOS/UEFI)
2. **Kernel**: Rotinas essenciais do SO
   - Gerenciamento de processos
   - Loader (carrega programas para memória)
   - Bootstrap (inicializa o SO)
3. **Drivers**: Gerenciamento de dispositivos E/S
4. **Shell**: Interface usuário-SO (CLI/GUI)
5. **Utilitários**: Ferramentas de sistema (antivírus, formatadores)
6. **Aplicativos**: Programas para usuários finais

### Processos vs Programas
| Conceito | Definição |
|----------|-----------|
| Programa | Arquivo em disco (código inativo) |
| Processo | Programa em execução (gerenciado pelo SO) |
| Tarefa | Sinônimo de processo |

## ⚙️ Gerenciamento de Execução
### Modelos de Sistemas
- **Monotarefa**: MS-DOS (um processo por vez)
- **Multitarefa**: Windows 95+ (time-sharing)
- **Multiprocessamento**: Uso de múltiplos núcleos

### API do Kernel
- Interface entre programas e rotinas do sistema
- Programas usuários rodam em modo restrito
- Acesso direto ao hardware apenas via chamadas do SO

## 💾 Particionamento e Boot
### BIOS Legacy (MBR)
- **MBR**: Setor 0 do disco (512 bytes)
  - Código de boot (446 bytes)
  - Tabela de partições (64 bytes)
  - Assinatura (2 bytes)
- **Limitações**:
  - Máx 4 partições primárias
  - Discos até 2TB

### UEFI Moderna (GPT)
- **Vantagens**:
  - Até 128 partições
  - Discos >2TB
  - Checksum de integridade
- **ESP (EFI System Partition)**:
  - Armazena bootloaders (.efi)
  - Formato FAT32 (universal)
  - Substitui o VBR tradicional

### Bootloaders Notáveis
| Sistema | Bootloader |
|---------|------------|
| Windows | BOOTMGR |
| Linux | GRUB |
| UEFI Genérico | bootx64.efi |

> "O kernel age como um tradutor entre o hardware complexo e os programas simplificados" - Princípio de Tanenbaum

*Diagrama implícito de boot:*
[UEFI] → [ESP] → [bootx64.efi] → [Kernel]
[BIOS] → [MBR] → [VBR] → [GRUB/NTLDR] → [Kernel]
