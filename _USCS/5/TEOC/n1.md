A Teoria da Computação estuda os fundamentos matemáticos da computação, utilizando modelos formais para entender limites e capacidades. 

- Computação: Processo de transformar entradas em saídas seguindo regras definidas (algoritmos).
- Algoritmo: Sequência finita de instruções para resolver um problema.
- Computabilidade: Estuda o que pode ou não ser resolvido computacionalmente.
- Decidibilidade: Determina se um problema pode ser resolvido por um algoritmo que sempre retorna uma resposta correta em tempo finito.
	- **Decidível**: Dado um numero inteiro n, n é par?
	- **Semidecidível**: Dado um programa P e uma entrada x, se P(x) parar, o algoritmo responde "sim".
	- **Indecidível**: Dados dois programas P1​ e P2​, eles produzem a mesma saída para todas as entradas?

- Formalismo matemático: descreve conceitos computacionais com precisão
    - compiladores: gramatica
    - algoritmos: tempo de exec
    - criptografia: fatoração primos 

- Autômato - **modelo de máquinas abstratas que processa informações**
    - AFD: estados finitos, transições, usado para **linguagens** **regulares**
        - regex
        - análise léxica
        - controle de processos industriais
    - AP: AFD com **memória**, não precisa de contexto
        - análise sintática
        - reconhecimento linguagem natural
        - calculos matematicos recursivos
    - MT: + poderoso, **fita** **infinita**,
        - define formalmente **computabilidade** e **decidibilidade**
        - problemas **indecidiveis** (parada)
        - base da arch dos comp modernos
    - Maquina RAM: memória endereçável, operações aritmeticas
        - complexidade algoritmica

Conjuntos
- Conjunto **potência**: **todos** os **subconjuntos**, incluindo ∅
- Subconjunto **próprio**: **exclui** o conjunto **original**
- **Complemento** A^c: tudo que não tem no A mas tem em U
- **Produto** **Cartesiano** A x B: **chuveirinho**, A{a,b}, B{1,2}, A x B{a1,a2,b1,b2}
    - Relação: subconjunto de produto cartesiano
        - **Reflexiva**: **duplicata**, para todo a, existe (a,a), b, existe (b,b) [deve conter no R tudo que tem no conjunto A]
        - **Simétrica**: **espelhado**, para todo (a,b) existe (b,a), pode ter (c,c), já é simétrico
        - **Antissimétrica**: **sem** **espelhado**, se tem (a,b) não pode ter (b,a)
        - **Transitiva**: se tem (1,2) e (2,3) deve haver (1,3)
    - Fechamento de Relações: ampliar uma relação para satisfazer uma propriedade (reflexiva, simetrica, etc)
        - O fechamento de uma relação é a menor relação que contém a original e que possui a propriedade em questão.

- Função f: A -> B, relação entre conjuntos A e B, todos os elementos de A relaciona com um apenas um elem de B
    A{1,2,3}, B{a,b,c} 
    f: A -> B
    f(1)=a
    f(2)=b
    f(3)=c
    - Tipos de funções
        - Função **Injetora**: **não repete saídas (y)**, cada elemento de B tem no máximo 1 correspondente em A 
        - Função **Sobrejetora**: **não sobra nada em B sem ter A**, todo elemento de B tem ao menos 1 correspondente em A
        - Função **Bijetora**: **ambos**, tudo se encaixa perfeitamente, cada elem de A corresponde a 1 elem de B e vice-versa

Prova por Indução Finita
- Demonstra que uma propriedade é valida para todos os números naturais a partir de um ponto inicial
- Autômatos finitos, linguagens formais, algoritmos recursivos
- Como fazer: S(n)=...
    - **Passo** **Base**: S(1), demonstra que é verdadeiro para um valor inicial, normalmente 0 ou 1
    - **Hípótese**: S(k), assume que é verdadeiro para k
    - **Passo** **Indutivo**: S(k+1), prova que k+1 é verdadeiro usando a hipótese

- alfabeto: conjunto finito de símbolos usados para formar cadeias.
- linguagem: conjunto de cadeias formadas a partir desse alfabeto.
    - linguagem finita: L={a,ab,bab}
    - linguagem infinita: L={0^n 1^n | n >= 1} (01, 0011, 000111, etc)
    - linguagem regular: regex ou AF
        - Uma linguagem é dita regular se existe um AFD ou AFND que a reconhece ou se pode ser descrita por uma expressão regular.

Autômatos Finitos 

- Autômatos Finitos: modelos computacionais com **memória** **limitada** (**estados** **finitos**), usados para **reconhecer** **linguagens** **regulares**.
    - **processa** cadeias de **símbolos**
    - **muda** de **estado** conforme as regras de transição
    - **aceita** ou **rejeita** a entrada com base no estado final
    - usado para reconhecer **padrões** **strings**
	- AFND pode virar AFD pois **todos os caminhos possíveis podem ser simulados em paralelo por um AFD**, usando conjuntos de estados do AFND como novos estados únicos no AFD
- linguagens **aceitas** por **AFs** são chamadas de **Linguagens Regulares**
- Regex: notação usada para descrever **padrões** em **cadeias** de **caracteres** (strings).
    - define uma linguagem (conjunto de palavras) que pode ser reconhecida por um Autômato Finito ou gerada por uma Gramática Regular.
    - é uma forma de especificar regras para encontrar, combinar ou manipular texto com base em padrões.
