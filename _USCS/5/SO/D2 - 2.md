# 🖥️ Processo de Boot 

## 🔌 Booting
- **Definição**: Sequência de inicialização do hardware até carregamento do SO
- **Componentes chave**:
  - BIOS/UEFI (firmware)
  - POST (autoteste)
  - Bootloader (GRUB, LILO)
  - Kernel do SO

## ⚙️ Firmware: BIOS vs UEFI

| Característica | BIOS (Legacy) | UEFI (Moderno)     |
| -------------- | ------------- | ------------------ |
| Interface      | Texto         | Gráfica (mouse)    |
| Tempo de boot  | Lento         | Rápido             |
| Partições      | MBR (até 2TB) | GPT (acima de 2TB) |
| Segurança      | Limitada      | Secure Boot        |
| Drivers        | Básicos       | Avançados          |
| Bootmanager    | GRUB, BOOTMGR | Não necessita      |
- BIOS contém todo o software básico para inicializar a placa-mãe e checar os dispositivos.
- Secure Boot impede a execução de softwares maliciosos durante o boot, verificando assinaturas digitais de bootloaders OSs e drivers.
- UEFI pode ser carregado pela Internet
## 🔍 Componentes Críticos

### 1. POST (Power-On Self-Test)
- Verifica hardware essencial:
  - Processador
  - Memória RAM
  - Dispositivos de armazenamento
  - Periféricos básicos

### 2. Setup/CMOS
- Memória não-volátil mantida por bateria
- Armazena configurações:
  - Data/hora
  - Sequência de boot
  - Parâmetros de hardware

### 3. Estruturas de Boot
- **MBR (Master Boot Record)**:
  - Setor 0 do disco (512 bytes)
  - Contém:
    - Código executável inicial (446 bytes)
    - Tabela de partições (64 bytes)
    - Assinatura (2 bytes)

- **GPT (GUID Partition Table)**:
  - Suporta discos >2TB
  - Múltiplas partições (>4 primárias)
  - Checksum para verificação

## 🔄 Fluxo Completo de Boot
1. Energização do hardware
2. Execução do firmware (BIOS/UEFI)
3. Execução do POST
4. Carregamento do bootloader
5. Carga do kernel na memória
6. Inicialização do sistema operacional
