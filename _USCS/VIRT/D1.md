## 🖥️ Virtualização: Conceitos e Aprofundamento

### 1️⃣ O que é Virtualização?
- **Definição**: Emulação e compartilhamento de recursos de hardware via software.
- **Componentes**:
  - Máquinas virtuais (VMs) utilizam CPU, memória, disco e rede do host.
  - **Hypervisors** gerenciam: emulação, alocação e isolamento dos recursos físicos.

### 2️⃣ Requisitos de Hardware
- **Processador**: Suporte a Intel VT-x ou AMD-V.
- **Memória RAM**: Suficiente para SO host + guests.
- **Armazenamento**: Espaço dedicado para host e VMs.
- **Placa-mãe**: Chipset compatível com virtualização.
- **Opcionais**: Placa de rede (depende do uso da VM).

### 3️⃣ Instruções ISA para Virtualização
#### **Intel VT-x**:
- `VMXON`, `VMXOFF`, `VMLAUNCH`, `VMEXIT` (gerenciamento do modo VM).
- `VMREAD`/`VMWRITE` (acesso à estrutura de controle).

#### **AMD-V**:
- `VMRUN`, `VMCALL` (início/comunicação da VM).
- `VMLOAD`/`VMSAVE` (gerenciamento de estado).

### 4️⃣ Requisitos de Software
- **Hypervisor**: Gerenciador de VMs.
- **SO convidado**: Executado dentro da VM.
- **Drivers**: Ferramentas para integração/performance.

### 5️⃣ Tipos de Hypervisors
| **Tipo 1 (Bare-Metal)**                             | **Tipo 2 (Hosted)**                                                |
| --------------------------------------------------- | ------------------------------------------------------------------ |
| Executa diretamente no hardware                     | Roda sobre um SO host                                              |
| Melhor desempenho e segurança                       | Mais fácil de configurar                                           |
| Usado em servidores (ESXi, KVM, Hyper-V, XenServer) | Para desktops (VirtualBox, VMware Workstation, Hyper-V, Parallels) |
|                                                     |                                                                    |

### 6️⃣ Benefícios e Problemas
#### ✅ **Benefícios Diretos**:
- Redução de custos com hardware.
- Isolamento de ambientes 
- Melhoria na utilização dos recursos de hardware
- Menor consumo de energia (muitas vezes)
- Flexibilidade e escalabilidade
- Facilidade de backup

#### 🌱 **Benefícios Indiretos**:
- Sustentabilidade (menos e-lixo).
- Menos espaço físico sendo utilizado
- Alta disponibilidade e agilidade operacional.
- Rápido provisionamento (cria VM rapidamente)

#### ❌ **Problemas Diretos**:
- Overhead de performance.
- Complexidade de configuração inicial.
- Complexidade de gerenciamento.
- Software incompatíveis
- Segurança menor (hypervisor +1 entrada)

#### 🔄 **Problemas Indiretos**:
- Proliferação descontrolada de VMs
- Diagnóstico mais complexo (camada de abstração).
- Custos com licenciamento e manutenção de hypervisor
- Complexidade na configuração de rede

### 7️⃣ Virtualização em Datacenters
- **Não elimina analistas**:
  - Reduz demanda por manutenção física.
  - Aumenta necessidade de especialistas em hypervisors, performance e segurança.

### 8️⃣ Subsistemas Críticos para Performance
1. **CPU**: Suporte a VT-x/AMD-V + núcleos suficientes.
2. **RAM**: Fator limitante principal (evitar swap).
3. **Armazenamento**: SSDs/NAS para melhor I/O.
4. **Rede**: Largura de banda (ex: 10GbE) e VLANs.

### 9️⃣ Fatores que Limitam Número de VMs
- **Recursos físicos**: CPU (vCPUs), RAM, armazenamento.
- **Hypervisor**: Limitações de escalabilidade.
- **Carga de trabalho**: VMs leves permitem maior densidade.

### 🔋 Virtualização como "TI Verde"
- **Eficiência energética**: Menos servidores = menos consumo.
- **Observação**: Só é eficiente se bem configurada (senão, pode aumentar gastos).

### 11️⃣ Overcommitment de CPU
- **Como funciona**:
  - Hypervisor escalona tempo de CPU entre vCPUs.
  - VMs não usam 100% dos recursos simultaneamente.
- **Exemplo**: 10 vCPUs em 4 núcleos físicos → tarefas são alternadas rapidamente.
