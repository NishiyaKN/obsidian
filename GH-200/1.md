- **GitHub Actions** -> scripts to automate tasks
	- Three types:
	- **Container actions**: environment is part of the action's code (hosted Linux only)
	- **JavaScript actions**: no environment in the code, run on a VM (hosted or on-prem Linux, Windows, macOS)
	- **Composite actions**: combine multiple steps within one action
- **GitHub Actions Workflow** -> process inside repo to automate dev lifecycle task (build, test, deploy)
	- Crete by adding a yml file on `.github/workflows`
	- Needs to have at least 1 job (which is associated with a runner)
