# 🖥️ Particionamento e Inicialização 

## 🗂️ Conceitos Fundamentais

### 1. Estruturas de Armazenamento
- **Setor**: Menor unidade (512 bytes ou 4K)
- **Trilha**: Círculos concêntricos no disco
- **CHS vs LBA**:
  - CHS: Endereçamento físico (Cilindro/Cabeça/Sector)
  - LBA: Endereçamento lógico sequencial, acesso de forma linear, + eficiente + capacidade

### 2. Particionamento
- **Propósito**:
  - Isolar sistemas operacionais
  - Organizar dados
  - Usar sistemas de arquivos diferentes
  - Melhorar desempenho e segurança

## ⚙️ Sistemas de Particionamento

### MBR (Master Boot Record)

- **Localização**: Setor 0 do disco (primeiro setor, fora de qualquer partição)
- **Estrutura**:
  - Código de boot (446 bytes)
  - Tabela de partições (64 bytes, sendo 16 bytes cada partição)
  - Assinatura (2 bytes)
- **Limitações**:
  - Discos até 2TB
  - Máximo 4 partições primárias

| Tipo Partição | Características     | Limitação MBR                           |
| ------------- | ------------------- | --------------------------------------- |
| Primária      | Bootável/Sistema    | Máx 4 por disco                         |
| Estendida     | Contêiner lógico    | 1 por disco                             |
| Lógica        | Dentro da estendida | Depende do SO e disco, deve ser uns 128 |
- Partição estendida em si **não armazena dados**


### GPT (GUID Partition Table)
- **Vantagens**:
  - Suporte a discos >2TB
  - Mais de 128 partições, cada um com 128 bytes
  - Checksum para integridade
- **Componentes**:
  - Protective MBR (proteção para não corromper o GPT)
  - Cabeçalho GPT primário (armazena metadados)
  - Entradas de partição
  - Backup do cabeçalho (cópia do cabeçalho primário e entradas de partição)
##  Volume Boot Record (VBR)

### 📌 Localização e Propósito
- **Onde**: Primeiro setor de uma partição ativa
- **Função principal**: Iniciar sequência de boot do sistema operacional
- **Contexto histórico**: Componente essencial em sistemas BIOS Legacy/MBR

### 💾 Volume Boot Code (VBC)
- Rotina que localize e inicia o bootloader presente na partição ativa do disco
### 💾 Disk Parameter Block (DPB)
**Contém informações vitais sobre:**
- 🗂️ **Sistema de arquivos**: FAT32, NTFS, ext4, etc.
- 📏 **Geometria do disco**:
  - Número total de setores
  - Tamanho do setor (geralmente 512 bytes)
  - Localização do primeiro setor de dados
- 🗄️ **Capacidades**:
  - Máximo de arquivos no diretório raiz
  - Tamanho máximo de arquivos

## 🔄 Fluxo de Boot com VBR
1. BIOS carrega MBR (setor 0 do disco)
2. MBR localiza partição ativa e executa seu VBR
3. **Volume Boot Code**:
   - Identifica o sistema de arquivos (via DPB)
   - Carrega o bootloader correspondente
4. Bootloader inicia o kernel do SO

## ESP (EFI SYSTEM PARTITION)
- Partição especial para discos GPT
- Contém arquivos necessário para o boot, incluindo bootloader
- Cada SO instala seu próprio bootloader, arquivos executáveis .efi
- Suporte a múltiplos SOs sem precisar sobrescrever um único setor 
- Mais seguro pela validação de assinatura com Secure Boot
