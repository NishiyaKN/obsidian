## 🌐 Visão Geral do Microsoft Azure  

### 📌 História e Evolução  
- **2010**: Lançado como **Windows Azure**, focado inicialmente em soluções Windows.  
- **2014**: Renomeado para **Microsoft Azure**, com suporte a Linux e open-source.  
- **Hoje**: 2ª maior plataforma de nuvem global (atrás da AWS), com **60+ regiões**.  

### 🚀 Principais Diferenciais  
- **Integração com Stack Microsoft**: Active Directory, Windows Server, SQL Server.  
- **Híbrido e Multicloud**: Conexão seamless com on-premises e outras nuvens.  
- **Foco em IA**: Serviços como **Azure OpenAI** e **Cognitive Services**.

## 💰 Modelos de Precificação  

### 1. **Pay-as-you-go**  
- Cobrança por uso (ex: VM Linux B1s = ~US$0.012/hora).  
- Ideal para cargas de trabalho imprevisíveis.  

### 2. **Azure Savings Plans**  
- Compromisso de uso (1 ou 3 anos) para descontos de até **72%**.  

### 3. **Free Tier**  
- **12 meses gratuitos**: 750h/mês de VMs B1s, 5GB Armazenamento.  
- **Sempre gratuitos**: 25+ serviços (ex: Azure Functions, Kubernetes).  

⚠️ **Atenção**: Monitorar uso para evitar cobranças acidentais.

## 🛠️ Serviços Principais por Categoria  

### 🔹 **Compute**  
- **Azure VMs**: Máquinas virtuais Windows/Linux.  
- **Azure Kubernetes Service (AKS)**: Orquestração de contêineres.  

### 🔹 **Banco de Dados**  
- **Azure SQL Database**: Banco relacional gerenciado.  
- **Cosmos DB**: Banco NoSQL multi-modelo.  

### 🔹 **IA + Machine Learning**  
- **Azure OpenAI**: Modelos GPT-4 para aplicações customizadas.  
- **Computer Vision**: Análise de imagens via API.  

### 🔹 **Segurança**  
- **Microsoft Defender for Cloud**: Proteção unificada contra ameaças.  
- **Azure Key Vault**: Gerenciamento de chaves criptográficas.

## 🖥️ Azure Portal: Interface de Gerenciamento  
- **Acesso**: [portal.azure.com](https://portal.azure.com).  
- **Recursos**:  
  - Criar e monitorar serviços.  
  - Configurar alertas de custo.  
  - Acessar documentação integrada.  

### 📌 Dicas para Iniciantes  
1. **Ativar MFA**: Proteja sua conta com autenticação em duas etapas.  
2. **Usar Tags**: Organize recursos por projeto/departamento.  
3. **Configurar Orçamentos**: Evite surpresas na fatura.
