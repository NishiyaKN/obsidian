## 🖥️ Virtualização: Conceitos Avançados e Tecnologias

### 12️⃣ Máquina Virtual (VM)
- **Definição**: Ambiente virtualizado que simula um computador físico via hypervisor.
- **Características**:
  - Isolamento completo do sistema host.
  - Executa seu próprio SO e aplicações.
  - Compartilha recursos físicos (CPU, RAM, disco) com outras VMs.

### 13️⃣ DirectPath I/O (PCI Passthrough)
- **Funcionalidade**: Permite acesso direto da VM a dispositivos físicos (ex: GPU, placa de rede).
- **Vantagens**:
  - Performance próxima do hardware nativo.
  - Compatibilidade com drivers específicos.
- **Limitação**: Dispositivo fica indisponível para o host e outras VMs.

### 14️⃣ Guest Additions (VirtualBox)
- **Propósito**: Melhora integração entre host e VM.
- **Recursos**:
  - Aceleração gráfica 2D/3D.
  - Compartilhamento de arquivos e clipboard.
  - Suporte a redimensionamento dinâmico de tela.
- **Instalação**: Montado como CD virtual dentro da VM.

### 17️⃣ Android Studio (Emulador como VM?)
- **ARM/x86**: 
  - Emulação ocorre se arquitetura for diferente (ex: ARM em x86).
  - Virtualização direta se usar imagem x86 em CPU com VT-x/AMD-V.
- **Hypervisor**: Utiliza WHPX, KVM, ou Hyper-V para acelerar.

### 18️⃣ Xcode Simulator (É VM?)
- **Não é VM**: 
  - Executa apps nativamente no macOS.
  - Simula APIs do iOS sem kernel separado.
  - Sem camada de virtualização.

### 19️⃣ Escalonador Windows 11/Server 2022
- **Prioridades**: Threads de 0 (baixa) a 31 (alta).
- **Quantum**: Tempo dinâmico por thread.
- **SMP**: Balanceamento entre núcleos físicos.
- **Starvation Prevention**: Promoção de threads em espera.

### 20️⃣ SMT (Intel Hyper-Threading / AMD SMT)
- **Funcionamento**: Núcleo físico executa múltiplas threads simultâneas.
- **Vantagem**: Aproveita ciclos ociosos do pipeline.
- **Configuração**: Típico 2 threads/núcleo (ex: 4C/8T).

### 21️⃣ Overprovisioning (Armazenamento)
- **Prática**: Alocar mais espaço virtual que o físico (ex: 2 TB virtuais em 1 TB real).
- **Risco**: Falha se capacidade física for atingida.

### 22️⃣ Overcommitment (CPU/RAM)
- **Técnica**: Alocar mais vCPUs/RAM que recursos físicos.
- **Base**: Nem todas VMs usam 100% simultaneamente.
- **Exemplo**: 30 vCPUs em 16 núcleos lógicos.

### 23️⃣ Overhead
- **Definição**: Recursos consumidos por operações indiretas (ex: hypervisor).
- **Impacto**: Redução de performance devido a camadas adicionais.

### 24️⃣ Memória Virtual no Windows (Host/VM)
- **Host**: 
  - `pagefile.sys` expande RAM usando disco.
  - Gerenciamento automático ou manual.
- **VM**: 
  - Balloon Driver "empresta" RAM não usada para hypervisor.
  - Permite overcommitment controlado.

### 25️⃣ RAID6 (16 HDDs) vs. NVMe PCIe 4.0
| **Métrica**   | **RAID6 (16 HDDs)**       | **NVMe PCIe 4.0 (4x)**  |
|---------------|---------------------------|--------------------------|
| Leitura       | ~2,000 MB/s               | ~7,000 MB/s             |
| Escrita       | ~1,000 MB/s (overhead)    | ~7,000 MB/s             |
| Latência      | 5–10 ms                   | 0.02–0.05 ms            |
| Caso de Uso  | Armazenamento massivo     | Baixa latência (DBs, VMs) |

### 📌 Dicas para Prova
- **RAID6**: Overhead de paridade dupla reduz velocidade de escrita.
- **NVMe**: PCIe 4.0 x4 = ~8 GB/s teóricos (7 GB/s práticos).
