### OS
- VFS: trata syscalls do file system (interface generica para fs)
- Formatação física: processo que acontece na produção do disco, é a organização física do disco, trilha, setor, cilindro
- Journaling: integridade dos dados
- **Formatação lógica**: processo que cria o sistema de arquivos
	- Antes de formatar um disco precisa particionar
	- Cluster: menor unidade de alocação de espaço no FS
		- Consiste em 1 ou mais setores
		- Mais eficiência, mas pode ocorrer fragmentação
- Arquivo: coleção nomeada de informações
	- User POV: menor porção de armazenamento logico
	- Quando aberto, FS procura a entrada na estrutura de diretórios e armazena as info numa tabela na RAM
- Diretório
	- Nível único, dois níveis, em árvore
- I-NODE: armazena info de um arquivo ou dir, mas não os seus dados
	- Número único no FS
	- Contém metadados do arquivo (permissions, owner, timestamp, size, pointers)
	- Permanece o mesmo para o arquivo, mesmo que seu nome mude
		- Nome é armazenado em uma entrada de diretório que mapeia para o seu I-Node correspondente
		- Permite que múltiplos nomes referenciem o mesmo I-Node (link)
- Superblock: possui info sobre o FS em si
	- Como por exemplo
		- Tamanho total do FS, número e tamanho dos blocks, número de inodes
	- Há cópias redundantes
- Gerência de espaços livres
	- Mapa de bits: faz um vetor de bits, 0 representa bloco livre, 1 bloco ocupado
		- Simples e eficiente
		- Permite alocação de blocos dispersos pelo disco
		- Requer espaço adicional para o vetor, mas não muito
		- Complexidade  na manutenção da consistência do mapa com o estado real do disco
	- Lista encadeada: 
		- Gerenciamento dinâmico com adição e remoção de entradas na lista
		- Facilidade de expansão
		- Mais difícil de conseguir espaço contíguo
		- Overhead com a busca por espaços livres
	- Tabela de blocos livres: identifica o primeiro bloco lívre e quantos blocos contíguos livres tem
		- Acesso mais rápido as blocos livres
		- Centraliza a informação, mais eficiente manipulação
		- Potencial fragmentação reduzida
- Alocação de arquivos
	- Contígua:
		- Simples, permite aceso aleatório e tem um bom desempenho
		- Fragmentação externa
		- Dificuldade no crescimento de arquivos
	- Encadeada: cada arquivo é uma lista encadeada de blocos
		- Não há fragmentação externa
		- Não permite acesso aleatório
	- Indexada: mantém todos os ponteiros de um arquivo em um bloco de indice
		- Permite acesso aleatório
		- Overhead do indice
		- Desperdiço de espaço com arquivos com poucos blocos
		- Utilizado nesse esquema de I-Node 
- Fragmentação Interna:
	- Processo é menor que o tamanho da partição
- Fragmentação Externa
	- Ocorre no particionamento dinâmico
	- Programas vão terminando e deixando buracos na memória
- MMU: converte endereços lógicos em endereços físicos
- Gerenciamento de memória
	- Alocação contígua
		- Monoprogramação
		- Desperdício se o processo não ocupa toda a memória
		- Tamanho da memória disponível = tamanho que o (único) programa pode usar 
	- Particionamento
		- Multitarefa
		- Fragmentação interna
		- Estática
			- Absoluta: programa só carrega no endereço físico especificado no próprio código
			- Realocável: referências a endereço são relativas ao início do seu código, pode ser carregado em qualquer local
				- Base + Deslocamento
		- Dinâmica
			- Ajustados de acordo com as necessidades dos processos
			- Cria uma nova partição vazia se ao colocar um processo tenha espaço sobrando
			- Depois realoca os processos de modo a deixar as partições vazias de um lado só
	- Segmentação
		- Divide a memória em segmentos lógicos (texto, dados, pilha, heap)
		- Ocorre fragmentação externa
		- Não ocorre fragmentação interna (quantidade de memória exata é alocada para cada segmento)
		- Princípio da localidade: tendência da CPU referenciar instruções e dados localizados em endereços próximos na RAM
		- Endereço lógico
			- Número de segmento
			- Posição no segmento
		- Tabela de Segmentos: 
			- Mapeia endereços físicos
			- Cada entrada possui base e limite 
	- Paginação
		- Páginas são blocos de mesmo tamanho
		- Soluciona fragmentação externa
		- Fragmentação interna ainda pode ocorrer (especificamente com a última página do programa)
	- Swapping
		- Relocação do programa na memória é dinâmica (durante execução)
		- Usa um registrador de alocação: recebe o endereço inicial da região da memória que será usado quando carregar na memória
		- Thrashing
			- Quando há pouco memória disponível, sistema fica quase que dedicado à realização de swapping
	- Memória virtual
		- Memória principal e secundária são combinadas
		- Adota endereçamento relativo
		- Permite maior número de processos compartilhando a memória principal
			- Apenas partes de cada processo estarão residentes
		- TLB: cache que armazena as traduções recentes de endereços da memória virtual para memória física
	- Memória virtual por paginação
		- Divisão do espaço de endereçamento virtual e real em páginas
			- Páginas Virtuais
			- Páginas Reais (frames)
		- Mapeamento por tabelas de páginas
			- Cada processo possui sua própria tabela de páginas
			- Cada página virtual do processo possui uma entrada na tabela (ETP)
		- Endereço virtual: formado pelo número da página virtual (índice da página) e por um deslocamento
		- Endereço físico: formado pela soma do endereço do frame + deslocamento do endereço virtual
		- Bit de Validade: quando o processo referencia um endereço virtual, a MMU verifica através do bit se a página que contém o endereço referenciado está ou não na memória
		- Page Fault: se não estiver na memória, ocorre o page fault, e o sistema transfere a página da memória secundária para a principal
			- Taxa de paginação: número de page faults gerados por cada processo em um determinado tempo
			- Processo passa do estado de execução para espera
		- Política de busca de páginas
			- Paginação por demanda: só leva para a memória as páginas realmente necessárias
				- Forma mais comum de implementar memória virtual
				- Reduz operações de IO e quantidade de memória usada por processo
			- Paginação antecipada: carrega além da página referenciada, outras páginas que podem ser eventualmente necessárias 
				- Determina quantos frames cada processo pode manter na mem principal
					- Alocação fixa: cada processo tem um número máximo de frames
					- Alocação variável: varia em função de sua taxa de paginação
		- Política de substituição de páginas
			- FIFO: substitui a primeira página que foi carregada na memória
			- LRU: substitui a página que está a mais tempo sem ser referenciada
			- LFU: substitui a página menos referenciada
	


## IOT
### IOT
- Camadas de implementação
	- Percepção (atuadores e sensores)
	- Rede (LPWAN, Wi-Fi, 5G)
	- Aplicação (server, dashboard)
- Protocolos
	- Leves: MQTT, CoAP
		- Simples, rápido, bom para sensores e dispositivos pequenos
	- Pesados: HTTP, HTTPs
		- Formal, cheio de regras, lento, usado pra sites e aplicações complexas
- MQTT - Message Queuing Telemetry Transport
	- Mensagens curtas
	- Baseado no publish/subscribe
		- Publisher: dispostivivo que envia mensagens para um topico
		- Subscriber: dispositivo que se inscreve em um topico para receber mensagens
		- Broker: server intermediario que gerencia topicos e distribui mensagens
	- Usa TCP/IP
	- MQTT-SN para redes sem TCP/IP
	- Header de apenas 2bytes
	- QoS - permite escolher o nivel de confiabilidade
		- QoS 0 (at most once) - envia sem confirmacao (pode ser perdida)
		- QoS 1 (at least once) - garante que sera entregue (pode ter duplicacao)
		- QoS 2 (exactly once) - entrega unica garantida (mais cara em procesamento)
- Componentes Fisicos
	- Microcontrolador
		- Circuito integrado programável (como um computador em um unico chip, tem CPU, RAM, ROM, IO)
		- Feito para controlar dispositivos de forma autônoma 
		- Diferente do microprocessador por este ultimo precisar de componentes externos
	- Sensores
		- Temperatura - RTD (resistance temperature detector), como o PT100, terçmistor, termopar
		- Proximidade - Indutivo, capacitivo, optico, ultrasonico
		- Pressão - piezoeletrico, resistivo, capacitivo
		- Umidade - higrometro eletronico, capacitivo, resistivo
		- Gás - MQ-series, eletroquimico, semicondutor
		- Luz - LDR (Light Dependent Resistor), fotodiodo, fototransistor
		- Movimento - PIR (Passive Infrared), Radar Doppler
		- Magnetico - Hall effect sensor, reed switch
		- Aceleração - MEMS (micro-Electro-Mechanical Systems)
		- Som - Microfone condensador, piezoeletrico, MEMS microphone
	- Atuadores
		- Motor DC - converte energia continua para movimento rotativo
		- Motor de passo - premite controle preciso de posição e angulo
		- Servomotor - controle de posição via circuito de realimentação
		- Relé eletromecânico - interruptor controlado eletricamente usando bobina magnetica
		- Solenoide Linear - bobina que cria campo magnético ao ser energizada, move um êmbolo em linha reta
		- Válvula Proporcional - regula passagem de fluidos proporcional ao sinal eletrico
		- Buzzer piezoeletrico - gera som a partir da vibração de um cristal
		- Peltier (TEC - Thermoeletic cooler) - cria diferença de temperatura, (um lado esfria, outro esquenta)
		- Resistência de Aquecimento - converte energia em calor pela reistencia do material condutor
		- Atuador piezoeletrico - transforma sinais eletricos em micro movimentos mecanicos de alta precisao
- Arquiteturas IoT
	- Edge Computing
		- Processamento diretamente no ou proximo ao disposito
		- Menor latencia, redução de trafigo na nuvem, util em tempo real
	- Fog Computing
		- Distribui o processamento por multiplos nodes locais para aliviar a nuvem
		- Escalabilidade
		- Maior capacidade de analise do que o Edge, reduz uso da nuvem
	- ETL - Extract, Transform, Load
		- Organiza dados dos sensores antes de analise, 
			- Trata falhas de coleta de dados, padroniza métricas e palavras
	- Interfaces
		- MQTT, REST API, WebSocket
		- OPC UA - Open Platform Communications - Unified Architecture
			- Padrão de interoperabilidade para troca de dados 
			- Inclui tipo de dado, unidade, status e tempo
			- Parece json
			- Cada dado é modelado como um nó com metadados (não apenas valores simples)
