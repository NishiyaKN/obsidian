## AI vs ML vs DL
**AI:** Ability of machines to mimic the cognitive abilities of human intelligence
**Machine Learning**: algorithms that enables machine to learn from and make predictions about data
**Deep Learning:** agorithms that learn complex data using neural networks
## Categories of AI
### Discriminative (Predictive) Model
- Identifies boundaries within data
- Recognize patterns
- Ex: Classify a cat or dog photo
### Generative Model
- Create something new
- Replicate data
## Types of problems solved by AI
### Binary classifications
- A variable belongs to a class or another
- Determine, for example, if the variable is true or false
### Multiclass classifications
- Classify a variable into 3 or more categories
### Regression
- Try to predict a numeric value based on another, continuous, value
- Ex: predict the stock price for a company
## Model Fit
### Overfitting
- Model performs well on training data, but poorly on evaluation data
- Learns the particulars of the data set too well
- Basically memorizing the training data, not learning
### Underfitting
- Model performs pooly on training data
- Don't capture the relationship between the input examples and target values
## Data Distribution
**Standard Normal Distribution (Z-distribution)**:
	**Mean of 0:** average of 0, data is centered around zero
	**Standard deviation of 1:** measures how dispersed the data points are from the mean (in this case typical distance is of 1 unit)
