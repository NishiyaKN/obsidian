- Built in Oracle Database 23ai
- Focus on information retrieval by efficient searches
- SQL support
- Allows to use models with API calls or load an ONNX model to the db
## Example of use
1. Upload an image (blob) 
2. Model transforms into a embedding
3. Queries the DB with the embedding
4. DB returns similar embeddings (similar images)
## Vector Datatype
- Table with vector columns
- Works with relational data
## Vector Distance Function
- Used to determine distance between vectors
	- Which means how similar or different they are
