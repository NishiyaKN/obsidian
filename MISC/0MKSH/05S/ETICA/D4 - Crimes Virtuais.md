## 1️⃣ Conceito de Crime (Base Legal)
- **Elementos do crime**:
  - Conduta humana (ação/postiva ou omissão/negativa)
  - Resultado material
  - Nexo causal
  - Tipificação legal

- **Proteção constitucional**:
  - 📜 Art. 5º, X: Inviolabilidade da intimidade
  - ✉️ Art. 5º, XII: Sigilo das comunicações
  - 🔐 EC 115/2022: Proteção de dados pessoais

## 2️⃣ Crimes Cibernéticos: Classificação
| Tipo | Características | Exemplo |
|------|----------------|---------|
| **Puros** | Consumados no meio digital | Invasão de sistemas |
| **Impuros** | Usam computador como meio | Fraude bancária |

## 3️⃣ Principais Crimes Virtuais

### 🔴 Cyberbullying (Lei 14.811/2024)
| Aspecto | Detalhes |
|---------|----------|
| **Pena** | 2-4 anos de reclusão |
| **Formas de prática** | |
| 🗣️ Hater | Ofensas/disseminação de ódio contra indivíduos/grupos |
| 🎭 Perfis falsos | Impersonação (falsificação de identidade) |
| 📸 Revenge porn | Divulgação de materiais íntimos como vingança |
| 💰 Sextortion | Extorsão para não divulgar conteúdo íntimo |
| 💬 Sexting | Entre menores de idade |
| 🤳 Happy slapping | Publicação de agressões físicas |
| 🔑 Subtração de logins | Para constrangimento/chantagem |
| 📊 Enquetes maldosas | Perguntas ofensivas em votações online |
| 🚨 Harassment | Coação para ações contra a vontade |

### 🎣 Phishing (Engenharia Social)
- **Objetivo**: Obter dados sensíveis (senhas, dados bancários)
- **Técnicas comuns**:
  - 📧 E-mails falsos (falsificação de remetentes)
  - 🌐 Sites clonados (bancos, redes sociais)
  - 📞 Chamadas falsas (suporte técnico falso)
  - 📱 Mensagens SMS/WhatsApp fraudulentas

### 🦠 Malware/Ransomware
- Software maliciosa para infectar dispositivos, permitindo acesso não autorizado, roubo de dados
- Lockbit (maior gangue global)
- Prejuízos:
  - 💸 Perda de dados
  - 🔓 Extorsão financeira

### ⚡ DDoS (Ataque de Negação de Serviço)
- **Método**: Sobrecarga de tráfego para derrubar serviços
- **Alvos frequentes**:
  - 🏛️ Sites governamentais
  - 🏦 Plataformas bancárias
  - 🛒 E-commerces
- **Impacto**: Indisponibilidade prolongada de serviços críticos

### 4️⃣ Roubo de Identidade & Fraude Online
- **Táticas**:
  - 🆔 Falsificação de documentos
  - 💳 Abertura de contas bancárias fraudulentas
  - 🛒 Compras online em nome de terceiros

### 5️⃣ Hackeamento de Sistemas
| Tipo                    | Características          | Exemplo                  |
| ----------------------- | ------------------------ | ------------------------ |
| Acesso não autorizado   | Violação de sistemas     | Invasão a servidores     |
| Alteração maliciosa     | Manipulação de dados     | Mudança em registros     |
| Interrupção de serviços | Paralisação de operações | Ataque a infraestruturas |

## 4️⃣ Legislação Brasileira

|-----|-------|------|
| 12.737/2012 | Invasão de dispositivo | 3m-1a |
| 13.718/2018 | Divulgação não consensual | 1-5a |
| 14.132/2021 | Perseguição virtual | 6m-2a |
| Código Penal | Furto eletrônico (Art. 155) | 1-4a |

## 5️⃣ Prevenção e Combate
- 🔒 **Proteção individual**:
  - Autenticação em 2 fatores
  - Backup periódico
  - Antivírus atualizado

## 6️⃣ Casos Relevantes

  - Envolveu FBI + Europol
  - 1.700 empresas afetadas nos EUA
