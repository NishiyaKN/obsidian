# Convolutional Neural Networks - Grid Like Data
- Automatically detect and learn local patterns and features in images and videos
- Reduces images into an easier to process form
- Used for image classification, object detection, 
## Layers
### Input Layer
- Accepts 2D (grayscale) or 3D (width x height x color channels) grid (image)
### Feature Extraction Layers
- Combination and repetition of multiple layers to extract features
#### Convolutional Layer
- Applies convolutional operations (math that allows the CNN to learn patterns and features)
	- Uses small filters known as **kernels** (square-shaped matrix of 3x3, 5x5, etc.)
	- Each filter "slides" across the image and detects specific features such as edges, lines, textures, etc. in the image
	- Creates a **feature map** that highlights the specific feature the filter was looking for
		- Each filter generates a map, in the end, all maps are combined to form the output of this layer
##### Operational Steps
1. Filter is placed on a small section of the image
2. Numbers in the filter are multiplied
3. Results from the multiplication are summed to a single number
4. This single number becomes a pixel in the **feature map**
5. Filter slides over to the next section, does the same thing, untill all the image is processed
#### Activation Function
- Allows the network to learn more complex and non-linear relationships in data
#### Pooling Layer
- Reduces spatial dimensions of the feature maps generated by the convolutional layer
#### Fully Connected Layer
- Makes final predictions or classifications based on the learned features
#### Softmax Layer
- Converts the output from the previous layer into probability scores.
- The class with the highest probability is the predicted class
#### Dropout Layer
- Regularization technique to prevent overfitting
### Classification Layers
- Ouput layer
## Limitations
- Requires massive data and computation power
- Overfitting happens with limited training data
- Typlical Black Box models
- Sensitive to input variations
